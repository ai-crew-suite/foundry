# `@ai-crew-suite/canonical-repo-assets`

## Overview

This package contains a manifest of static files to copy from this repo to other AI Crew Suite repos to keep them in sync, and the canonical copy of those files. It is used in a GitHub workflow action, which is executed from the Foundry repo and maintained in the Actions repo.
